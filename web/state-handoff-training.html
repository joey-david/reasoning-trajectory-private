The question behind the run

Can one explicit state token turn local skill into long-range composition?

Qwen can apply one state update and use a supplied state. It often fails when it must compress a whole history and then use the result. We train two adapters with the same data and compute. Only one must pass through an explicit three-bit state.

Gradient accumulation combines eight microbatches into an effective batch of 64 sequences. Accumulation continues across the epoch boundary, so two epochs total 625 optimizer steps per adapter.

The pilot gate

What would count as evidence?

+10 pointsExplicit handoff beats outcome-only at h4 or h8.
CI > 0The context-level bootstrap lower bound stays positive.
≥90%Histories ending at the same state yield the same token.
Closes gapPredicted-state use moves well toward gold-state use.

The key test: not whether extra training helps, but whether forcing the model through one interchangeable three-bit state helps more than the matched outcome-only control on longer, unseen programs.
