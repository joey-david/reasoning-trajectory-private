How does reasoning move inside a language model?

We captured the internal state of a model at every generated token, then tested whether reasoning breaks into natural, portable steps. The answer is more interesting than a clean yes or no.

The short answer Structure is real, but the “right step” depends on what you want the step to do.

The intuition

Words are visible. Computation is not.

A model writes an answer one at a time. Underneath, each token is accompanied by a long numerical vector: a . String those vectors together and reasoning becomes a through .

Our original hope was that meaningful reasoning steps would appear as sharp bends or peaks in that trajectory. We designed five experiments to give that idea every reasonable chance to succeed.

02 · H1 and H2

We looked for a spike. We found a wave.

First, we asked whether textual boundaries coincide with sharp latent events. Then we used a symbolic engine to locate exact arithmetic updates without asking a human or another model to judge them.

Gk → Gk+1

What is a symbolically verified update?

A deterministic parser reads the generated arithmetic. When a token interval completes a valid new relation, binding, calculation, check, or final extraction, the symbolic execution graph changes. That interval is a .

73rd

Path-length percentile

The total movement inside a real update exceeded 73% of length-matched control windows. Updates are active, not flat.

19%

Peak share

The single largest token-to-token move accounts for only 19% of movement. No one token performs the whole update.

98%

Effective width

Meaningful movement occupies 98% of the update interval. This is the clearest evidence against a narrow spike.

17%

Net / path ratio

Only 17% of traveled distance becomes straight-line displacement. The trajectory moves, turns, and partially doubles back.

Put together:

Real updates contain more latent motion than ordinary matched windows, but that motion is broad and direction-changing. “Wave” is an intuition for this distributed process, not a claim that the curve is sinusoidal.

Magnitude spikes recovered only 3–5% of symbolic updates. transitions found 52–64%, but with low precision. Forcing numbered or sentence-separated formatting changed net displacement more than interval width or peak concentration.

04 · H4

The information is there. It is not naturally arranged for us.

We compared update vectors from different problems. Positive pairs performed the same arithmetic operation with no shared literals; negative pairs came from the same problem but performed different operations.

Raw geometry AUC 0.394

Same-operation pairs are not naturally closer.

learn a linear projection →

Supervised projection AUC 0.957

Operation identity becomes strongly separable.

What this positive result means

A simple learned linear map can expose arithmetic operation information on held-out questions. The model’s activations contain a reusable signal about whether it is adding, subtracting, multiplying, or dividing.

What it does not mean

The raw space does not organize itself into obvious operation clusters. AUC does not establish causality, a symbolic internal language, or a universal definition of a reasoning step.

What does ROC-AUC mean?

is the probability that a classifier ranks a randomly chosen correct trace above a randomly chosen incorrect one. 0.5 is chance; 1.0 is perfect. It measures ranking, not calibrated confidence.

06 · Token-level no free lunch

There may be no objective-independent “correct step”

We stopped asking for one preferred boundary and let every token-to-token transition compete. Each segmentation received the same number of boundaries. Then we scored it under five different goals.

Semantic

No tested segmentation is good at everything

Utility is normalized so random selection is 0 and the objective-specific oracle is 1. The strongest method’s weakest objective is only .020. Changing the minimum segment length from one to eight tokens leaves the conclusion intact.

Independent human-semantic ontology

A 122B model labeled “thought units” from the text

Qwen3.5-122B marked complete verbatim intervals as planning, deriving a value, checking, correcting an error, extracting an answer, and related operations. We aligned those spans back to SmolLM token activations.

07 · What survives

Reasoning has structure, but not one canonical ruler

Supported

Reasoning operations are represented

Arithmetic operation and human-semantic labels are strongly decodable with supervised linear models on held-out questions.

Supported

Real updates contain distributed activity

Symbolic update intervals move more than controls, but the movement covers almost the whole interval and changes direction.

Not supported

One token is the atomic write event

Peak share is low, effective width is high, and raw spikes recover very few symbolic updates.

Not supported

One segmentation serves every purpose

Answer, object, correctness, compression, and semantic objectives select sharply different token boundaries.

A “reasoning step” is not simply discovered in the activation stream. It is selected relative to an objective.

Limits

  • The main corpus is arithmetic reasoning.
  • Most activation analyses use the final layer.
  • The causal result tests one component and layer.
  • Semantic labels are model-generated silver annotations.

Next decisive tests

  • Replicate answer-relative MI/HSIC peaks.
  • Repeat on code, proofs, and debugging traces.
  • Test transfer across model families and scales.
  • Build a smaller human-audited semantic benchmark.
