| **1. Qwen2.5-32B matched-history factorization and explicit handoff**<br><br>Run: [`runs/Qwen2.5-32B-Instruct/interventions/state_abstraction_matched_history`](runs/Qwen2.5-32B-Instruct/interventions/state_abstraction_matched_history)<br><br>Evidence: [`factorization_summary.json`](runs/Qwen2.5-32B-Instruct/interventions/state_abstraction_matched_history/depth_relief/factorization_summary.json), [`explicit_handoff/summary.json`](runs/Qwen2.5-32B-Instruct/interventions/state_abstraction_matched_history/depth_relief/explicit_handoff/summary.json), [`state_abstraction/information_summary.json`](runs/Qwen2.5-32B-Instruct/interventions/state_abstraction_matched_history/depth_relief/state_abstraction/information_summary.json)<br><br>Scale: 1,920 cases over 30 program contexts. | **Result:** Read, Update, and constituent transition checks were perfect. At h2, one-pass Compose reached 13.44%, while Synthesize, deterministic executor handoff, and LM self-handoff reached 76.98%. Gold and stepwise explicit handoff reached 100%. At h4, native Synthesize and Compose were near the 12.5% eight-state chance rate, while stepwise use of supplied states remained reliable.<br><br>**Deduction:** The model has the local transition and state-use operations but does not reliably consolidate a long operation history into one reusable current state. Explicit handoff separates state production from state use and locates most of the failure in history-to-state production.<br><br>**Limit:** This establishes the mechanism on a synthetic finite-state task, not on general reasoning. |
| **2. Qwen2.5-7B explicit decimal LoRA and recursive continuation confirmation**<br><br>Run: [`runs/Qwen2.5-7B-Instruct/interventions/state_handoff_killtest`](runs/Qwen2.5-7B-Instruct/interventions/state_handoff_killtest)<br><br>Evidence: [`evaluation/comparison_summary.json`](runs/Qwen2.5-7B-Instruct/interventions/state_handoff_killtest/evaluation/comparison_summary.json), [`continuation/confirmation/summary.json`](runs/Qwen2.5-7B-Instruct/interventions/state_handoff_killtest/evaluation/continuation/confirmation/summary.json), [`continuation/gate.json`](runs/Qwen2.5-7B-Instruct/interventions/state_handoff_killtest/evaluation/continuation/gate.json), [`evaluation/information_summary.json`](runs/Qwen2.5-7B-Instruct/interventions/state_handoff_killtest/evaluation/information_summary.json)<br><br>Scale: 9,600 confirmation cases over 30 unseen contexts, with one- and two-operation recursive blocks through h32. | **Result:** The first terminal explicit-handoff LoRA reached 100% on unseen-context h2, then fell to 12.08% at h4 and 11.77% at h8 when asked to synthesize the full history in one pass. The same learned short mapping, applied repeatedly through explicit decimal states, achieved 100% state accuracy, answer accuracy, local closure, final-state following, and same-state agreement through h32.<br><br>**Deduction:** Short-horizon training did not create length extrapolation inside one forward pass. It did create a closed transition module whose output could serve as its next input without error. The execution protocol, not another weight update, converted local competence into long-horizon composition.<br><br>**Limit:** Recursive execution uses more model calls than one-pass Compose. It is an externally run reusable module, not evidence that the native model forms the same state internally. |
| **3. Qwen2.5-7B compressed two-bit interface**<br><br>Run: [`runs/Qwen2.5-7B-Instruct/interventions/state_interface_rate_controls`](runs/Qwen2.5-7B-Instruct/interventions/state_interface_rate_controls)<br><br>Condition evidence: [`compressed_2bit/summary.json`](runs/Qwen2.5-7B-Instruct/interventions/state_interface_rate_controls/evaluation/interfaces/compressed_2bit/summary.json), [`compressed_2bit/cases.jsonl`](runs/Qwen2.5-7B-Instruct/interventions/state_interface_rate_controls/evaluation/interfaces/compressed_2bit/cases.jsonl)<br><br>Contract: four codes for eight equiprobable states, so declared capacity is two bits while the true state entropy is three bits. | **Result:** Code accuracy and local closure were 100% at h2, h4, h8, and h16. Final-answer accuracy was exactly 50% at every horizon. The learned code retained exactly two state bits.<br><br>**Deduction:** The behavioral result reaches the exact information limit: four codes can distinguish only four classes of an eight-state process, so each code leaves two states possible and caps exact final lookup at 50%. This is direct evidence that the state channel's declared rate constrains reasoning behavior.<br><br>**Limit:** The partition was designed, so this is a clean capacity control rather than evidence that the model discovered an optimal compression scheme on its own. |
| **4. Qwen2.5-7B canonical opaque three-bit interface**<br><br>Run: [`runs/Qwen2.5-7B-Instruct/interventions/state_interface_rate_controls`](runs/Qwen2.5-7B-Instruct/interventions/state_interface_rate_controls)<br><br>Condition evidence: [`canonical_opaque/summary.json`](runs/Qwen2.5-7B-Instruct/interventions/state_interface_rate_controls/evaluation/interfaces/canonical_opaque/summary.json), [`canonical_opaque/cases.jsonl`](runs/Qwen2.5-7B-Instruct/interventions/state_interface_rate_controls/evaluation/interfaces/canonical_opaque/cases.jsonl)<br><br>Contract: eight global opaque codes for eight states, exactly three bits. | **Result:** Final-adapter answer accuracy was 74.27% at h2, 58.65% at h4, and 42.19% at both h8 and h16. All eight codes were used and code entropy was 2.99 bits, but the emitted code retained only 1.29 bits about state when pooled across horizons. Exact same-state agreement at h16 was 34.17%. Gold-code continuation was 100%.<br><br>**Deduction:** Sufficient channel capacity does not force a stable state representation. The model can use the full codebook while assigning codes inconsistently across histories. The missing property is canonicalization: different paths to the same state must select the same code.<br><br>**Limit:** Decimal states worked perfectly while opaque states did not, so pretrained meaning attached to decimal tokens may supply part of the canonicalization. |
| **5. Qwen2.5-7B redundant four-bit interface**<br><br>Run: [`runs/Qwen2.5-7B-Instruct/interventions/state_interface_rate_controls`](runs/Qwen2.5-7B-Instruct/interventions/state_interface_rate_controls)<br><br>Condition evidence: [`redundant_4bit/summary.json`](runs/Qwen2.5-7B-Instruct/interventions/state_interface_rate_controls/evaluation/interfaces/redundant_4bit/summary.json), [`redundant_4bit/cases.jsonl`](runs/Qwen2.5-7B-Instruct/interventions/state_interface_rate_controls/evaluation/interfaces/redundant_4bit/cases.jsonl)<br><br>Contract: sixteen codes, with two valid representatives for each of eight states. | **Result:** Answer accuracy was 97.71% at h2, 80.63% at h4, 63.85% at h8, and 59.48% at h16. At h16, exact target-code accuracy was only 35.73%, because the model often switched between the two codes that decode to the same state. All sixteen codes were used; pooled code entropy was 3.99 bits and state information was 1.86 bits.<br><br>**Deduction:** Extra capacity improves short-horizon reliability but weakens exact invariance by allowing more than one representation of the same state. This suggests a rate--reliability--invariance tradeoff. A representation may remain semantically valid as an equivalence class even when it does not use one exact token per state.<br><br>**Limit:** The present summary measures exact token agreement and semantic answer accuracy, but it does not yet give a full causal test of independently predicted alternate representatives. |
| **6. Qwen2.5-7B context-bound three-bit interface**<br><br>Run: [`runs/Qwen2.5-7B-Instruct/interventions/state_interface_rate_controls`](runs/Qwen2.5-7B-Instruct/interventions/state_interface_rate_controls)<br><br>Condition evidence: [`context_bound/summary.json`](runs/Qwen2.5-7B-Instruct/interventions/state_interface_rate_controls/evaluation/interfaces/context_bound/summary.json), [`context_bound/cases.jsonl`](runs/Qwen2.5-7B-Instruct/interventions/state_interface_rate_controls/evaluation/interfaces/context_bound/cases.jsonl)<br><br>Contract: eight codes, but the state-to-code permutation changes with program context. Test contexts are disjoint from training contexts. | **Result:** Answer accuracy stayed near the 12.5% chance rate: 12.50% at h2, 12.71% at h4, 11.88% at h8, and 11.67% at h16. The emitted code retained only 0.019 state bits when pooled across horizons.<br><br>**Deduction:** An interface that has enough nominal capacity but changes meaning across contexts does not transfer. Reusable state requires a shared code contract, not merely structured outputs or enough symbols.<br><br>**Limit:** This is an intended negative control. It does not show that every form of context-dependent representation must fail; it shows that this arbitrary unseen permutation does. |
| **7. Gold-code continuation and causal substitution analysis across opaque conditions**<br><br>Run: [`runs/Qwen2.5-7B-Instruct/interventions/state_interface_rate_controls`](runs/Qwen2.5-7B-Instruct/interventions/state_interface_rate_controls)<br><br>Evidence: [`interfaces/comparison_summary.json`](runs/Qwen2.5-7B-Instruct/interventions/state_interface_rate_controls/evaluation/interfaces/comparison_summary.json), [`canonical_opaque/interchange_summary.json`](runs/Qwen2.5-7B-Instruct/interventions/state_interface_rate_controls/evaluation/interfaces/canonical_opaque/interchange_summary.json), [`redundant_4bit/interchange_summary.json`](runs/Qwen2.5-7B-Instruct/interventions/state_interface_rate_controls/evaluation/interfaces/redundant_4bit/interchange_summary.json) | **Result:** With supplied gold codes, canonical and redundant consumers achieved 100% same-state preservation and 100% different-state donor following; recipient-state preservation under a different-state code fell to 0%. Yet predicted-code accuracy and invariance were much lower, especially at long horizons.<br><br>**Deduction:** State use and state production are separate abilities. The downstream model has learned what the supplied code means and lets it determine the answer. The main opaque-interface failure lies in producing a stable correct code from varied histories.<br><br>**Limit:** The current substitution analysis reuses `gold_final` calls. Canonical same-state donors supply the identical token, and the test does not establish interchangeability among independently predicted codes. It supports consumer causality, not the full learned-code causality claim. |
| **Cross-run deduction: capacity, closure, and canonicalization are distinct requirements**<br><br>Compared runs: 32B matched history, 7B decimal continuation, and all four 7B rate-control conditions above. | **Deduction:** A reusable state interface needs at least four distinct properties: enough capacity to retain the state; a shared meaning across contexts; closure under repeated transition; and consistent selection of equivalent states across histories. The experiments separate these properties. Two bits fail by capacity. Context-bound codes fail shared meaning. Canonical opaque codes have enough capacity but weak canonicalization and closure. Redundant codes improve reliability while allowing path-dependent representatives. Decimal codes satisfy all four on this task.<br><br>**Stronger framing:** Models can learn state channels and local transitions without organizing them into one stable computational contract. The central problem is not simply storing enough information; it is making that information reusable under repeated computation. |
| **Cross-run limits and required confirmation**<br><br>Applies to all runs above. | The addition histories are structured: `path_code` sets the first operation, middle operations follow a context-dependent cycle, and the last operation forces the chosen endpoint. Recursive execution also spends more test-time forward passes than one-pass Compose. Before making a broad reasoning claim, test IID and adversarial operation streams, add a matched test-time-compute baseline, intervene on predicted donor codes, run multiple seeds, and confirm in a second task domain and model family. The present evidence is strong for a precise mechanism in this benchmark, not yet for reasoning in general. |
